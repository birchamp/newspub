## Wrap text around any box

You can now make text flow around a text box, shape or picture that sits on top of a text box. Before this release only pictures did this, and nothing in the app could change it.

1. Select the box on top. Anything you draw later is on top; otherwise use **Move to front**.
2. In the Format panel, under **Arrange**, set **Wrap text**:
   - **Square**: around the box's edges.
   - **Tight**: follows the outline, so it hugs an ellipse.
   - **Top and bottom**: the text stops above the box and continues below it.
   - **Through**: may fill open areas inside the shape.
   - **None**: the text runs underneath.
3. Use **Distance from text** to set the gap. Wrapping starts at 0.1 in.

If you select several objects, the setting applies to all of them.
