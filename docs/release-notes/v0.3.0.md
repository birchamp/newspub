## Open your Microsoft Publisher files

newpub now opens `.pub` files from Publisher 98, 2000, 2002/2003 and 2007/2010 and later. Use File → Open, drag the file onto the window, or choose Open With → newpub in your file manager. The import brings in:

- pages, with page size and orientation;
- text boxes, including linked boxes that continue a story;
- character and paragraph formatting;
- pictures (clip art too), shapes, groups and tables.

Fonts you don't have are replaced by bundled fonts of the same width, so lines break in the same places. The Design Checker lists them. Not imported yet: WordArt, fonts embedded in the file, gradient and pattern fills, and Publisher 97 files.

## New in the editor

- **Text flow.** Insert → Text File puts a .txt or .docx file into a text box. When text doesn't fit, click the red **+** on the box, or use **Link to Next Box**, then click an empty box to continue the story there. **Break Link** and **Flow onto New Pages** are on the Format panel. You can now type in shapes, and **Clear Formatting** removes character formatting.
- **Tables.**
  - Click into a cell and type.
  - Tab and Shift+Tab move between cells, and Tab in the last cell adds a row.
  - Shift-click or drag across cells to select a block.
  - The Format panel's Table card inserts and deletes rows and columns, merges and splits cells, and sets column width, row height, the table style and cell fill.
- **Pages and guides.**
  - Right-click a page thumbnail to move it up or down, insert, duplicate or delete it.
  - Drag from the top or left ruler to make a guide. Drag a guide to move it, or drag it back onto the ruler to remove it.
- **Styles.** Home → Styles makes a paragraph or character style from the formatting at the cursor, and applies or deletes styles.
- **Review.** **Properties** sets the title, author and language. **Design Checker** finds:
  - text that doesn't fit;
  - empty text boxes;
  - objects off the page;
  - fonts that aren't installed;
  - pictures that can't be found.

  Click a problem to jump to it.
- **Templates.** In the Save dialog, **Save as Template** keeps a publication in *My templates*. Your templates appear on the start screen, with previews.
- **Scheme previews.** Hovering over a colour or font scheme shows it on the page before you apply it.
- Unsaved work is safe: newpub asks before closing, starting a new publication or opening another. After a crash, it offers your work back. Pictures dragged in from the desktop land where you drop them.

## Fixes

- Zooming in very far no longer crashes.
- Tab no longer jumps from the page into a panel field.
- WMF clip art with a flipped coordinate system now shows in full instead of one corner.
